# Mini-TSFM — educational decoder-only patch Transformer

A self-contained PyTorch teaching example inspired by Karpathy's mini-GPT, adapted for continuous, univariate time-series forecasting.

## Run

```bash
pip install torch matplotlib
python mini_tsfm.py --steps 300
```

To smoke-test: `python mini_tsfm.py --steps 3 --eval-interval 2`.

The script trains on 160 procedurally generated series, validates on 32 *different* synthetic series, forecasts 48 steps on another unseen series, and saves a plot.

## Files

- `mini_tsfm.py` — fully commented, minimal end-to-end implementation.
- `mini_tsfm_architecture.drawio` — editable draw.io architecture (open with app.diagrams.net).
- `quick_test.png` — plot after only 3 optimization steps; **not** an example of a well-trained model.

## Tensor shapes

- Observed history: `(B, 128)`
- Training window: `(B, 136)` = 17 patches × 8 observations
- Context-only standardization with per-series mean and standard deviation
- Patches: `(B, 17, 8)`
- Training input: `(B, 16, 8)`; shifted target `(B, 16, 8)`
- Patch embeddings: `(B, 16, 64)`
- Transformer output: `(B, 16, 64)`
- Forecast head output: `(B, 16, 8)`
- Last token output: forecast of next 8 steps
- Rollout: repeat to cover the requested horizon; undo normalization

## Important limitations

- This is a *pedagogical approximation* of a TSFM, not a faithful reproduction of TimesFM, Chronos, Toto, or any particular published model.
- Synthetic pretraining across many series illustrates the foundation-model setup; real general-purpose forecasting requires diverse, large-scale data and evaluation.
- Uses MSE point forecasts, not quantiles or a learned probabilistic distribution.
- Assumes equal-spacing, no missing values, a single numerical channel per series, and a context length divisible by patch size.
- Uses absolute learned position embeddings, a finite context of 16 patches, and iterative patch decoding rather than direct arbitrary-horizon decoding.
- Validation uses distinct synthetic series, but generated by the same family of processes. It is not a real-world generalization benchmark.
